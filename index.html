# 財富紀律 V4.1｜免隱藏資料夾版 這一版把 GitHub Actions 工作流程另外拆成一個看得見的檔案， 避免 Windows 把 `.github` 隱藏，導致漏傳。 ## 第一步：更新網站檔案 把以下 6 個檔案上傳到 Repository 根目錄並覆蓋舊檔： - index.html - styles.css - app.js - manifest.json - sw.js - market-data.json 請不要把「工作流程檔案_請勿直接放根目錄.yml」直接放在根目錄； 它必須建立在 GitHub 指定位置。 ## 第二步：在 GitHub 建立工作流程 在 Repository 首頁操作： 1. 按 `Add file` 2. 選 `Create new file` 3. 在檔名欄完整輸入： `.github/workflows/update-market-data.yml` 4. 打開本資料夾中的： `工作流程檔案_請勿直接放根目錄.yml` 5. 全選內容、複製，貼進 GitHub 編輯區 6. 按 `Commit changes` 建立成功後，Repository 的 Actions 頁面左側會出現： `Update Taiwan market data` ## 第三步：第一次執行 1. 點上方 `Actions` 2. 左側點 `Update Taiwan market data` 3. 點右側 `Run workflow` 4. 再按綠色 `Run workflow` 5. 等待約 1–2 分鐘 6. 回到網站重新整理 ## 為什麼要這樣做？ GitHub 只會執行放在： `.github/workflows/` 裡面的 YAML 檔案。放在 Repository 根目錄不會生效。 ## 網站網址 https://jamietolink-arch.github.io/wealth-discipline/
